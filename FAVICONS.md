# Favicons da Sheik Multimarcas

Coloque estes arquivos nesta pasta `public/` para que sejam usados automaticamente pelo site:

- `favicon.ico`
- `favicon-16x16.png`
- `favicon-32x32.png`
- `apple-touch-icon.png` (180x180)
- `favicon-192x192.png`
- `favicon-512x512.png`

O `index.html` já referencia os arquivos e o `site.webmanifest` já está configurado.
